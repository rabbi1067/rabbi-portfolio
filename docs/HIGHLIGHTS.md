# Selected Highlights

A compact, curated gallery lives immediately after the Home hero and before About. There is no View all button. Images, captions and titles are part of the same link and navigate directly to a section or project.

## Edit

Administrator Studio → Home & About → Selected Highlights. The same fields are available in the existing GitHub content manager under Profile.

- Toggle the gallery and automatic scrolling.
- Edit the eyebrow label, heading, subtitle and up to 20 cards.
- Each card supports an image upload, alt text, title, category, short caption, framing, ordering and visibility.
- Use an internal destination such as `#education`, `#skills`, `#experience`, `#reviews`, `#certifications`, or `#project-orbitcart`.
- Deleted/unpublished projects and hidden destination sections are excluded during publishing. A project hidden by a category filter or the six-card preview is revealed when its highlight is clicked.

## Interaction

The gallery scrolls gently while visible. Hover or keyboard focus pauses movement; touch scrolling temporarily pauses autoplay. Previous/next and Play/Pause controls work independently. Reduced-motion preferences disable autoplay by default. Loop duplicates are hidden from assistive technology and excluded from keyboard tab order. No animation runs while the page/gallery is out of view, or after Pause is selected.

The current eight highlights use existing portfolio assets: OrbitCart, ICPC 2024, THIRA, CityFix, AI/ML training, Southeast University, CodeChef streak and collaborator feedback. Gallery selection is separate from project publication order and can be edited at any time.
